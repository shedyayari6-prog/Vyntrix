# Vyntrix portfolio site

A responsive React + Vite portfolio landing page inspired by the Vyntrix design concept.

## Run locally
1. Install Node.js (18+ recommended).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. Run `npm run build` to create the production build in `dist/`.

## Customize
- Main page and project cards: `src/main.jsx`
- Colors, layout, responsive styles: `src/styles.css`
- Project links are configured in the `projects` array near the top of `src/main.jsx`.

The Cachi Shop, GymUp, Taqyeem website, Taqyeem Google Play listing, and Zorble URLs are linked from the portfolio. Project visuals are custom CSS mockups so the page does not depend on remote screenshot services.
